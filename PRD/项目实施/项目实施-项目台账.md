## 2. 功能目标与核心价值

### 2.1 功能目标

项目台账模块旨在为项目经理和管理层提供项目的全生命周期管理能力。

**主要目标：**
- 实现项目立项审批，规范项目启动流程
- 建立项目基本信息和状态的统一视图
- 实现项目实施计划的可视化管理（甘特图）
- 管理项目的审批记录
- 记录项目全过程的操作日志

### 2.2 核心价值

- **对公司**：建立完整的项目实施信息库，提升管理规范化水平。
- **对项目经理**：提供统一的计划制定和进度跟踪工具。

## 3. 业务背景与使用场景

### 3.1 使用场景

| S01 | 项目立项 | 基于订单创建项目，提交立项审批 | 项目经理、销售经理 |
| S02 | 计划制定 | 引用标准实施方案或自定义实施计划，制定项目时间表 | 项目经理 |

#### 三、功能点说明

**页面布局：**
- 采用卡片容器布局，包含标题区、搜索筛选区、数据表格区。

**搜索功能：**
- 支持按关键字（项目名称或编号）、关联订单、项目状态、负责人、创建日期、客户名称等条件搜索。
- 关键字搜索支持模糊匹配。

**表格设计：**
- **列名**：项目编号、项目名称、客户、订单、状态、进度、负责人、创建时间、操作。
- **操作列**：根据项目状态动态展示操作按钮，操作项为文字链接样式。
  - **未立项/已驳回**：编辑、提交审批、删除
  - **审批中**：无操作
  - **已立项**：启动、取消
  - **执行中**：编辑、暂停、完成
  - **已暂停**：恢复、取消
  - **已完成/已取消**：无操作
- **状态列**：使用标签展示（未立项、审批中、已立项、已驳回、执行中、已暂停、已完成、已取消）。
- **进度列**：百分比显示。

**关键操作流程：**
- **新建项目**：点击新建按钮 -> 填写信息（名称、订单、负责人） -> 确定 -> 跳转详情页。
- **删除项目**：仅无实施记录和审批记录的项目可删除。

#### 四、业务规则
- 项目名称必填且唯一。
- 项目编号自动生成：`XM-YYYYMMDD-XXX`。
- 项目必须关联订单，且仅能关联状态为“执行中”的订单。

### 6.2 页面2：项目台账详情页

#### 一、页面功能说明

展示单个项目的完整信息，包括基本信息、实施计划、审批记录等。支持查看、编辑、提交审批、更新进度等操作。

#### 二、UI 示意

```
┌───────────────────────────────────────────────────────────────────────────────┐
│  页面头部：← 返回  XX项目  [编辑] [提交立项审批] [删除]                        │
│  统计信息：项目进度  任务总数  已完成 ...                                      │
│  标签页：[基本信息] [实施计划] [审批记录] [项目日志]                           │
└───────────────────────────────────────────────────────────────────────────────┘
```

#### 三、功能点说明

**基本信息标签页：**
- 展示项目编号、名称、关联订单、客户、状态、进度、负责人、日期范围、描述等。
- **立项信息**：包括项目编号、项目名称、关联订单、客户名称、项目负责人、立项报告、计划开始日期、计划完成日期、项目描述。
- **执行信息**：包括项目状态、项目进度、实际开始日期、实际完成日期、执行备注。
- **立项报告**：支持附件上传功能，用于提交项目立项所需的文档。
- 编辑模式下支持修改基本信息（状态字段除外）。

**提交立项审批：**
- 仅“未立项”或“已驳回”状态可用。
- 提交后状态变为“审批中”。

#### 四、业务规则

**项目编辑规则：**
- **状态限制**：只有处于"未立项"或"已驳回"状态的项目可以编辑全部信息（除了只读字段）；"执行中"的项目仅支持编辑执行信息。
- **只读字段**：项目编号、客户名称（自动带出）、项目状态（自动流转）不可直接修改。
- **关键字段**：关联订单在项目"执行中"后不可修改。

**提交审批规则：**
- **状态限制**：只有处于"未立项"或"已驳回"状态的项目可以提交立项审批。
- **前置校验**：提交前系统自动校验必填字段（项目名称、关联订单、负责人、计划时间）是否完整。
- **状态变更**：提交成功后，项目状态变更为"审批中"，锁定项目编辑功能。

### 6.3 页面3：实施计划标签页（项目台账详情页）

#### 一、页面功能说明

管理项目的实施计划，支持甘特图和列表视图，支持任务的增删改查及引用标准方案。

#### 二、UI 示意

```
┌─────────────────────────────────────────────────────────────────────────┐
│  [+ 添加任务] [引用标准方案] [甘特图视图] [列表视图]                     │
│  甘特图区域 / 任务列表区域                                               │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 三、功能点说明

**甘特图视图：**
- 展示任务时间线、进度。
- 支持父子任务层级（最多两层）。
- **全屏功能**：支持全屏查看和编辑。

**任务列表视图：**
- 表格展示任务名称、日期、负责人、进度、状态、操作。

**任务操作：**
- **添加任务**：支持创建父任务或子任务。
- **引用标准方案**：从标准方案库导入任务模板（二期规划）。
- **删除任务**：删除父任务时递归删除子任务。

#### 四、业务规则

**任务添加/编辑规则：**
- **必填项**：任务名称、开始日期、结束日期、负责人为必填项。
- **时间规则**：任务开始日期不能晚于结束日期；子任务的时间范围只能在父任务范围内。
- **层级规则**：当前最多支持两层任务结构（父任务 -> 子任务）；子任务不能再创建子任务。
- **父任务逻辑**：
    - 父任务的进度 = 所有子任务进度的平均值（自动计算，只读）。

**任务删除规则：**
- **普通任务**：删除时弹出二次确认框。
- **父任务**：删除父任务时，系统提示"该操作将一并删除所有子任务"，确认后递归删除。
- **依赖校验**：如果任务被其他任务依赖（前置任务），需先解除依赖关系才能删除（二期规划）。

### 6.4 页面4：审批记录标签页（项目台账详情页）

#### 一、页面功能说明

展示项目的审批记录（立项审批、验收审批等），数据从OA系统同步。

#### 二、UI 示意

表格展示：审批节点、审批人、审批状态、审批意见、审批时间。

#### 三、功能点说明

- 支持手动同步审批状态。
- 按时间倒序排列。

### 6.5 页面5：项目日志标签页（项目台账详情页）

#### 一、页面功能说明

展示项目的动态日志，记录与项目状态相关的操作以及任务执行相关的操作。

#### 二、UI 示意

表格形式展现，列包括：时间（到时分秒）、用户、操作、描述。

#### 三、功能点说明

- **自动记录**：系统自动记录关键操作，无需人工干预。
- **记录内容**：
    - **项目状态变更**：立项、审批、启动、暂停、恢复、完成、取消等。
    - **项目信息变更**：修改项目基本信息。
    - **任务操作**：创建任务、更新任务进度、删除任务等。
- **排序**：按时间倒序排列，最新的操作在最前面。

## 7. 页面交互逻辑说明

- **列表页 -> 详情页**：点击项目编号或查看按钮。

## 9. 业务规则汇总

### 9.1 项目编号规则
- 格式：`XM-YYYYMMDD-XXX`

### 9.2 项目状态流转

| 当前状态 | 动作 | 目标状态 | 说明 |
|---|---|---|---|
| 未立项 | 提交审批 | 审批中 | 新建项目后的初始状态 |
| 已驳回 | 提交审批 | 审批中 | 审批被驳回后重新提交 |
| 审批中 | 审批通过 | 已立项 | OA审批通过，项目正式立项 |
| 审批中 | 审批驳回 | 已驳回 | OA审批驳回 |
| 已立项 | 启动项目 | 执行中 | 项目准备就绪，正式开始执行 |
| 执行中 | 暂停项目 | 已暂停 | 暂停项目实施 |
| 已暂停 | 恢复执行 | 执行中 | 恢复项目实施 |
| 执行中 | 确认完成 | 已完成 | 所有任务完成，项目结束 |
| 未立项/已驳回/已立项 | 取消项目 | 已取消 | 项目终止 |

### 9.3 审批规则
- **提交限制**：只有"未立项"或"已驳回"状态的项目可提交立项审批。
- **状态同步**：系统需定时同步OA审批状态；审批通过后自动更新为"已立项"，审批驳回后更新为"已驳回"。

### 9.4 订单关联规则
- 创建项目时，只能选择状态为“执行中”的订单。
