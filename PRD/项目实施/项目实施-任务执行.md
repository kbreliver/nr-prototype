## 2. 功能目标与核心价值

### 2.1 功能目标

任务执行模块旨在为实施人员提供高效的任务执行和交付工具，确保项目按计划推进。

**主要目标：**
- 实现任务的分配、查看和状态更新
- 提供软件交付（账户开通、模块启用）的标准化流程
- 提供硬件交付（发货、验收、安装）的标准化流程
- 支持任务看板管理

## 3. 业务背景与使用场景

### 3.1 使用场景

| 场景编号 | 场景名称 | 场景说明 | 典型用户 |
|---------|---------|----------|---------|
| S05 | 软件交付 | 执行软件产品账户开通、模块启用等交付任务 | 实施人员、技术支持 |
| S06 | 硬件交付 | 执行硬件发货、验收、安装调试等交付任务 | 实施人员、物流人员 |
| S07 | 任务管理 | 查看待办任务，更新任务进度和状态 | 所有实施人员 |

## 4. 用户角色与职责

| 角色 | 职责 | 权限范围 |
|------|------|----------|
| 项目经理 | 分配任务、监控进度 | 查看所有任务 |
| 实施人员 | 执行交付任务、更新进度 | 查看、编辑自己负责的任务 |
| 技术支持 | 执行软件交付任务 | 查看、编辑软件交付相关任务 |
| 物流人员 | 执行硬件交付任务 | 查看、编辑硬件交付相关任务 |

## 5. 业务流程

### 5.1 任务执行流程

```
开始
 │
 ├──► 接收任务
 │    ├─► 查看待办任务列表
 │    └─► 确认任务要求和时间节点
 │
 ├──► 执行任务
 │    ├─► 软件交付：账户开通 -> 模块启用
 │    └─► 硬件交付：发货 -> 验收 -> 安装 -> 确认
 │
 ├──► 更新进度
 │    ├─► 更新任务百分比
 │    ├─► 更新任务状态（进行中 -> 已完成）
 │    └─► 填写交付记录/上传附件
 │
 └──► 结束
```

## 6. 功能需求说明

### 6.1 页面：任务执行页面

#### 一、页面功能说明

该页面是独立的任务管理中心，展示所有项目的任务列表，支持列表视图和看板视图切换。默认显示当前用户待办任务。

#### 二、UI 示意

**任务列表页（列表视图）：**
```
┌───────────────────────────────────────────────────────────────────────────┐
│  任务执行管理                    [列表视图] [看板视图]                     │
│  ┌─────────────────────────────────────────────────────────────────────┐  │
│  │ 搜索筛选区：项目、任务类型、负责人、计划时间、关键字                    │
│  └─────────────────────────────────────────────────────────────────────┘  │
│  ┌─────────────────────────────────────────────────────────────────────┐  │
│  │ 状态统计徽标区：[全部(50)] [待办(10)] [进行中(30)] [已完成(10)]        │
│  └─────────────────────────────────────────────────────────────────────┘  │
│  ┌─────────────────────────────────────────────────────────────────────┐  │
│  │ 数据表格区：任务名称 | 项目 | 类型 | 状态 | 负责人 | 计划时间 | 进度 |  │
│  └─────────────────────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────────────────────┘
```

**任务看板视图：**
- 分为三列：待办、进行中、已完成。
- 卡片展示：任务名称、项目、负责人、进度。

#### 三、功能点说明

**视图模式：**
- **列表视图**：详细展示任务信息，支持按状态徽标快速筛选。
- **看板视图**：直观展示任务状态流转，支持拖拽更新状态。

**筛选规则：**
- **默认显示**：默认选中“待办”状态徽标；默认显示当前用户待办任务。
- **项目筛选**：
    - 选项范围：当前用户参与的、状态为执行中的项目。
    - 特殊权限：拥有查看所有项目权限的人员（如项目总监和管理层）可查看所有状态为执行中项目。
- **负责人筛选**：
    - 默认值：默认选中当前用户。拥有查看所有项目权限的人员不用默认选中当前用户。
    - 选项范围：默认仅显示当前用户；特殊权限人员可查看所有用户。

**任务详情：**
- 点击任务进入详情页，根据任务类型展示不同内容：
    - **软件交付**：账户开通、账号创建、模块启用配置（从客户方案读取）。
    - **硬件交付**：硬件发货、到货验收、安装调试、安装完成确认。

#### 四、业务规则

- **状态流转**：待办 -> 进行中 -> 已完成。支持回退（需说明原因）。
- **软件交付规则**：模块启用配置必须从客户方案读取，不可随意添加。
- **硬件交付规则**：必须按顺序执行各环节（发货 -> 验收 -> 安装 -> 确认）。
- **权限控制**：普通用户只能看自己的任务；管理者可看全部。

#### 五、字段定义

**通用任务字段**：任务ID、项目、名称、类型、状态、负责人、进度、计划/实际时间、描述。

**软件交付特有**：关联软件产品、交付类型、模块启用记录（模块ID、状态、启用时间）。

**硬件交付特有**：关联硬件设备、交付环节、物流信息、验收结果、安装调试记录、附件。

## 7. 页面交互逻辑说明

- **拖拽交互**：看板视图下拖拽卡片可更新任务状态。
- **点击交互**：列表/看板点击任务 -> 打开任务详情页。
- **筛选交互**：点击状态徽标 -> 列表过滤对应状态任务。

## 8. 权限与角色配置

| 角色 | 权限 |
|------|------|
| 实施人员 | 查看/执行自己的任务；默认看待办 |
| 项目经理 | 查看/管理自己项目的所有任务 |
| 项目总监/管理员 | 查看/管理所有任务 |
