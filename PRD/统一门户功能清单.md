# 企业统一门户功能清单

## 一、登录页

| 页面   | 功能     | 功能描述                     |
| ------ | -------- | ---------------------------- |
| 登录页 | 账号登录 | 用户通过账号密码登录系统     |
| 登录页 | 忘记密码 | 提供密码找回或重置入口       |
| 登录页 | 企微登录 | 通过企业微信进行单点登录认证 |

---

## 二、门户首页

| 页面 | 功能模块 | 功能 | 功能描述 |
| --- | --- | --- | --- |
| 门户首页 | 常用应用 | 默认常用应用展示 | 展示系统预设的常用应用入口 |
| 门户首页 | 常用应用 | 常用应用设置 | 用户通过弹框新增或删除常用应用 |
| 门户首页 | 快捷导航 | 默认快捷导航 | 展示系统预设快捷操作入口 |
| 门户首页 | 快捷导航 | 快捷导航设置 | 支持用户自定义新增/删除快捷导航 |
| 门户首页 | 待办工作 | 待办数量徽标 | 显示当前待办数量 |
| 门户首页 | 待办工作 | 待办列表 | 展示待处理任务列表 |
| 门户首页 | 待办工作 | 待办跳转 | 点击待办跳转至对应业务系统页面 |
| 门户首页 | 待办工作 | 查看全部待办 | 弹框展示完整待办列表 |
| 门户首页 | 消息中心 | 消息数量徽标 | 显示未读消息数量 |
| 门户首页 | 消息中心 | 消息列表 | 展示消息摘要列表 |
| 门户首页 | 消息中心 | 消息详情查看 | 弹框展示消息详情（来源、时间、内容） |
| 门户首页 | 消息中心 | 消息已读同步 | 点击消息后调用源系统接口更新已读状态 |
| 门户首页 | 消息中心 | 查看全部消息 | 弹框展示完整消息列表 |
| 门户首页 | 新闻公告 | 新闻/公告展示 | 按"公司要闻/公告通知"分类展示 |
| 门户首页 | 新闻公告 | 查看全部 | 跳转至新闻公告列表页 |
| 门户首页 | 知识库入口 | 分类卡片展示 | 以分类卡片形式展示知识库入口 |
| 门户首页 | 知识库入口 | 进入知识库 | 点击进入知识库首页 |

---

## 三、知识库（前台）

| 页面   | 功能     | 功能描述                   |
| ------ | -------- | -------------------------- |
| 知识库 | 文档检索 | 支持关键词搜索知识文档     |
| 知识库 | 热榜展示 | 展示热门文档或高频访问内容 |
| 知识库 | 分类浏览 | 按分类浏览知识内容         |
| 知识库 | 标签管理 | 通过标签进行内容筛选       |
| 知识库 | 文档上传 | 支持上传知识文档           |
| 知识库 | 数据统计 | 统计文档访问、下载等数据   |

---

## 四、后台管理

### 4.1 用户与权限管理

| 页面 | 功能模块 | 功能 | 功能描述 |
| --- | --- | --- | --- |
| 后台管理 | 用户管理 | 组织同步 | 从企业微信同步组织及用户信息 |
| 后台管理 | 用户管理 | 用户扩展信息维护 | 编辑用户及组织扩展字段（预留） |
| 后台管理 | 权限管理 | 用户角色分配 | 为用户分配系统角色 |
| 后台管理 | 角色管理 | 角色定义 | 定义系统角色类型 |
| 后台管理 | 角色管理 | 角色分类 | 包括超级管理员、账号管理员、知识库管理员、应用中心管理员、普通用户 |

---
