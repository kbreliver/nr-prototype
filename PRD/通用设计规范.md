## 一、页面布局规范

### 1.1 列表页面布局

列表页面采用统一的布局结构，包含以下区域：

#### 页面结构
```
┌─────────────────────────────────────────┐
│  页面容器（内边距：24px）                │
│  ┌───────────────────────────────────┐ │
│  │  卡片容器                           │ │
│  │  ┌─────────────────────────────┐ │ │
│  │  │  标题区 + 主要操作按钮        │ │ │
│  │  └─────────────────────────────┘ │ │
│  │  ┌─────────────────────────────┐ │ │
│  │  │  搜索筛选区                  │ │ │
│  │  └─────────────────────────────┘ │ │
│  │  ┌─────────────────────────────┐ │ │
│  │  │  数据表格区                  │ │ │
│  │  └─────────────────────────────┘ │ │
│  └───────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

#### 区域说明

**1. 标题区**
- 位置：卡片顶部
- 内容：页面标题（左侧）+ 主要操作按钮（右侧）
- 主要操作：新建、批量操作、导出等
- 布局：左右分布，标题左对齐，按钮右对齐

**2. 搜索筛选区**
- 位置：标题区下方
- 布局：搜索条件横向排列，自动换行
- 搜索条件类型：
  - 关键字输入框（支持模糊搜索）
  - 下拉选择框（状态、类型等）
  - 日期范围选择器
  - 其他筛选条件
- 操作按钮：搜索按钮（主要按钮）+ 重置按钮（次要按钮）
- 间距：搜索区与表格区之间间距为16px

**3. 数据表格区**
- 位置：搜索区下方
- 功能：数据展示、分页、排序、多选
- 列设置：
  - 关键信息列（编号、名称等）可点击跳转详情
  - 状态列使用标签展示
  - 操作列固定在右侧
- 分页：底部显示分页控件，支持快速跳转和每页条数选择

**4. 操作列**
- 位置：表格最右侧，固定列
- 操作项：查看、编辑、删除等
- 样式：文字链接样式，小号按钮
- 条件显示：根据数据状态动态显示可用操作

### 1.2 详情页面布局

详情页面采用标签页组织多个信息模块：

#### 页面结构
```
┌─────────────────────────────────────────┐
│  页面容器（内边距：16px）                │
│  ┌───────────────────────────────────┐ │
│  │  页面头部                          │ │
│  │  - 返回按钮 + 标题 + 状态标签      │ │
│  │  - 操作按钮组（右侧）              │ │
│  └───────────────────────────────────┘ │
│  ┌───────────────────────────────────┐ │
│  │  统计信息卡片（可选）              │ │
│  └───────────────────────────────────┘ │
│  ┌───────────────────────────────────┐ │
│  │  标签页容器                         │ │
│  │  ┌─────────────────────────────┐ │ │
│  │  │  标签1：基本信息              │ │ │
│  │  │  ┌─────────────────────────┐ │ │ │
│  │  │  │  卡片：表单/信息展示     │ │ │ │
│  │  │  └─────────────────────────┘ │ │ │
│  │  ├─────────────────────────────┤ │ │
│  │  │  标签2：其他信息             │ │ │
│  │  └─────────────────────────────┘ │ │
│  └───────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

#### 区域说明

**1. 页面头部**
- 返回按钮：左侧返回列表
- 标题信息：页面标题、编号、状态标签
- 操作按钮：编辑、保存、提交等，位于右侧

**2. 统计信息卡片（可选）**
- 适用场景：需要展示关键统计数据的详情页
- 布局：横向排列多个统计项
- 样式：大号数字 + 小号标签，不同数据使用不同颜色区分

**3. 标签页区域**
- 组织方式：使用标签页将相关信息分组
- 标签命名：基本信息、详细信息、关联信息等
- 内容布局：每个标签页内使用卡片分组展示
- 审批流程页签：
  - 适用场景：当数据存在审批流程时，在详情页中增加"审批流程"页签
  - 展示方式：使用表格形式展示审批详情
  - 表格列：审批节点、审批人、审批状态、审批意见、审批时间
  - 排序：按审批时间倒序排列（最新的在前）
  - 状态展示：审批状态使用标签展示，遵循状态颜色规范

**4. 表单布局**
- 布局方式：多列布局，充分利用页面宽度
- 字段排列：相关字段横向排列，每行2-3个字段
- 标签宽度：统一标签宽度，保持对齐

### 1.3 页面间距规范

- **页面内边距**：列表页24px，详情页16px
- **卡片间距**：卡片之间间距16px
- **区域间距**：标题区与搜索区之间16px，搜索区与表格区之间16px
- **表单间距**：表单项之间垂直间距24px
- **按钮间距**：按钮组内按钮间距8px

## 二、功能组件规范

### 2.1 搜索功能设计

#### 搜索条件类型

**1. 关键字搜索**
- 用途：支持名称、编号等文本字段的模糊搜索
- 提示文字：明确说明搜索范围（如"合同名称或编号"）
- 交互：支持回车键快速搜索，支持清空按钮

**2. 下拉选择**
- 用途：状态、类型等枚举值筛选
- 多选支持：下拉框支持多选功能，可同时选择多个选项进行筛选
- 选项：提供"全部"或"请选择"选项，支持清空
- 宽度：根据选项文字长度设置，通常120-160px
- 显示：多选时显示已选数量或选中项标签

**3. 日期范围选择**
- 用途：时间维度的筛选
- 格式：统一使用"YYYY-MM-DD"格式
- 宽度：240px

#### 搜索操作

- **搜索按钮**：主要按钮样式，带搜索图标
- **重置按钮**：次要按钮样式，清空所有搜索条件并刷新数据
- **位置**：搜索条件右侧，右对齐

### 2.2 数据表格设计

#### 表格列设计

**1. 列名对齐**
- 所有列名（表头）统一居中对齐显示

**2. 编号列**
- 样式：文字链接样式，点击跳转详情页
- 颜色：主题色
- 对齐：数据居中对齐
- 用途：合同编号、订单编号、方案编号等唯一标识字段

**3. 名称列**
- 对齐：数据居中对齐
- 用途：合同名称、方案名称、产品名称等

**4. 状态列**
- 展示方式：使用标签（Tag）展示
- 对齐：数据居中对齐
- 颜色规范：见"状态颜色规范"章节
- 宽度：100px
- 用途：合同状态、审批状态、订单状态等

**5. 枚举类列**
- 对齐：数据居中对齐
- 用途：类型、分类等枚举值字段

**6. 数值列**
- 对齐：数据右对齐
- 格式：统一数字格式，金额保留2位小数
- 用途：金额、数量、百分比等数值字段

**7. 文字列**
- 对齐：数据左对齐
- 格式：超出部分显示..,悬停后用tooltip形式显示全部内容

**8. 操作列**
- 位置：表格最右侧，固定列
- 对齐：左对齐
- 宽度：根据操作项数量，通常200-240px
- 操作项：文字链接样式，小号按钮

#### 表格功能

**1. 分页功能**
- 位置：表格底部
- 功能：页码跳转、每页条数选择、总数显示
- 每页选项：10、20、50、100条
- 显示格式："共 X 条"

**2. 排序功能**
- 标识：列标题显示排序图标
- 支持排序的字段类型：
  - 编号类字段（合同编号、订单编号等）
  - 名称类字段（合同名称、方案名称等）
  - 日期类字段（创建时间、更新时间、签订日期等）
  - 数值类字段（金额、数量等）
  - 状态类字段（合同状态、审批状态等）
- 不支持排序的字段：
  - 操作列
  - 描述类长文本字段
  - 附件、图片等非文本字段
- 交互：点击列标题切换升序/降序

**3. 多选功能**
- 位置：表格第一列
- 用途：批量操作
- 交互：支持全选/取消全选

**4. 加载状态**
- 展示：表格区域显示加载动画
- 时机：数据加载、搜索、分页切换时

#### 表格布局和高度

**1. 表格区域高度**
- 表格区域高度自适应页面高度
- 确保整个页面不出现纵向滚动条

**2. 表格滚动**
- 当数据行数较多时，表格内容区域出现纵向滚动条
- 表格表头固定，仅内容区域滚动
- 分页控件始终固定在表格底部，不随内容滚动

**3. 布局要求**
- 页面采用弹性布局，表格区域占据剩余空间
- 表格容器设置为固定高度，内容区域可滚动
- 分页控件始终可见，位于表格底部

### 2.3 操作按钮设计

#### 按钮类型

**1. 主要操作按钮**
- 样式：主要按钮（Primary）
- 用途：新建、保存、提交等核心操作
- 位置：页面顶部或操作区左侧
- 图标：重要操作可配图标

**2. 次要操作按钮**
- 样式：默认按钮
- 用途：取消、重置、导出等
- 位置：主要按钮右侧或操作区右侧

**3. 危险操作按钮**
- 样式：危险按钮（红色）
- 用途：删除、终止等不可逆操作
- 确认：必须使用确认提示

**4. 文字链接按钮**
- 样式：链接样式
- 用途：表格操作列、次要操作
- 大小：小号按钮

#### 按钮状态

- **可用状态**：正常显示
- **禁用状态**：灰色，不可点击（如批量操作未选择数据时）
- **加载状态**：显示加载动画，禁用点击

### 2.4 状态标识设计

#### 状态标签使用

状态信息统一使用标签（Tag）展示，不同状态使用不同颜色：

**状态颜色规范**
- **成功/通过**：绿色（success）
- **进行中/处理中**：蓝色（processing）
- **失败/驳回**：红色（error）
- **默认/待处理**：灰色（default）
- **警告**：橙色（warning）

**状态标签样式**
- 圆角矩形
- 文字居中
- 颜色背景 + 白色文字

### 2.5 审批流程展示

审批流程有两种展示方式，根据使用场景选择：

#### 方式一：列表页右侧抽屉展示

**适用场景**：在列表页中快速查看审批流程

**展示方式**：使用右侧抽屉（Drawer）展示，内容使用时间线（Timeline）形式

**抽屉设置**
- 位置：从右侧滑出
- 宽度：600px
- 标题："审批流程"

**时间线展示**
- 节点信息：节点名称、状态标签、审批人、审批时间、审批意见
- 状态标识：
  - 已通过：绿色圆点
  - 已驳回：红色圆点
  - 待审批：蓝色圆点
  - 未审批：灰色圆点
- 信息层级：节点名称（粗体） + 状态标签（同行），详细信息（小字，灰色）

#### 方式二：详情页表格展示

**适用场景**：在详情页中查看完整的审批记录

**展示方式**：在详情页标签页中增加"审批流程"或"审批记录"页签，使用表格形式展示

**表格设计**
- 表格列：
  - 审批节点：节点名称，居中对齐
  - 审批人：审批人姓名，居中对齐
  - 审批状态：使用标签展示，居中对齐，遵循状态颜色规范
  - 审批意见：审批意见内容，左对齐，支持文本省略
  - 审批时间：审批时间，居中对齐，格式"YYYY-MM-DD HH:mm:ss"
- 排序：按审批时间倒序排列（最新的审批记录在前）
- 对齐规则：遵循表格数据对齐规范（见"2.2 数据表格设计"章节）
- 空状态：无审批记录时显示空状态提示

## 三、交互设计规范

### 3.1 搜索交互流程

**搜索触发方式**
1. 点击搜索按钮
2. 在输入框中按回车键

**搜索反馈**
- 搜索时显示加载状态
- 搜索完成后更新表格数据
- 无结果时显示空状态提示

**重置操作**
- 清空所有搜索条件
- 恢复默认数据展示
- 重置分页到第一页

### 3.2 表格操作交互

**行选择交互**
- 点击复选框选择单行
- 点击表头复选框全选/取消全选
- 选中状态视觉反馈明显

**排序交互**
- 点击列标题切换排序
- 排序图标显示当前排序状态
- 支持多列排序（可选）

**分页交互**
- 点击页码跳转
- 输入页码快速跳转
- 切换每页条数自动刷新

**操作列交互**
- 鼠标悬停高亮
- 点击操作项执行对应操作
- 危险操作需要确认

### 3.3 表单操作交互

**表单验证**
- 实时验证：失焦时验证
- 提交验证：提交时验证所有必填项
- 错误提示：字段下方显示错误信息

**表单保存**
- 保存草稿：不验证，保存当前状态
- 提交：验证通过后提交
- 保存反馈：成功/失败提示

**表单取消**
- 有未保存数据：提示确认
- 无未保存数据：直接返回

### 3.4 确认操作交互

**删除确认**
- 使用确认提示框
- 提示信息明确说明删除对象
- 确认按钮使用危险样式

**批量操作确认**
- 显示操作影响的数据数量
- 明确说明操作后果
- 提供取消选项

**不可逆操作确认**
- 必须使用确认提示
- 提示信息强调操作不可逆
- 需要用户明确确认

## 四、视觉设计规范

### 4.1 页面间距规范

**页面级间距**
- 列表页内边距：24px
- 详情页内边距：16px

**组件级间距**
- 卡片间距：16px
- 区域间距：16px
- 表单项间距：24px
- 按钮组内间距：8px

### 4.2 状态颜色规范

**状态标签颜色**
- 成功/通过：绿色
- 进行中/处理中：蓝色
- 失败/驳回：红色
- 默认/待处理：灰色
- 警告：橙色

**数据颜色**
- 金额/数值：根据正负使用不同颜色（正数绿色/黑色，负数红色）
- 进度/比率：使用进度条颜色系统

### 4.3 按钮样式规范

**按钮尺寸**
- 主要按钮：默认尺寸
- 表格操作：小号按钮
- 图标按钮：根据图标大小

**按钮颜色**
- 主要按钮：主题色（蓝色）
- 默认按钮：灰色边框
- 危险按钮：红色
- 文字链接：主题色文字

### 4.4 信息层级规范

**文字层级**
- 标题：大号、粗体
- 副标题：中号、粗体
- 正文：默认字号、常规
- 辅助信息：小号、灰色

**视觉层级**
- 主要信息：正常颜色、正常字号
- 次要信息：灰色、小字号
- 标签信息：彩色背景、白色文字

## 五、特殊场景设计

### 5.1 空状态设计

**无数据状态**
- 显示空状态图标
- 提示文字："暂无数据"
- 提供操作建议（如"点击新建按钮创建"）

**无搜索结果**
- 显示搜索图标
- 提示文字："未找到相关数据"
- 提供重置搜索建议

### 5.2 加载状态设计

**页面加载**
- 整个页面显示加载动画
- 保持页面结构，避免布局跳动

**数据加载**
- 表格区域显示加载动画
- 保持表格结构

**操作加载**
- 按钮显示加载状态
- 禁用按钮防止重复操作

### 5.3 错误状态设计

**表单错误**
- 字段下方显示错误信息
- 错误字段高亮显示
- 错误信息红色文字

**操作错误**
- 使用错误提示消息
- 明确说明错误原因
- 提供解决建议（如需要）

## 六、设计原则

### 6.1 一致性原则

- 相同功能使用相同的交互方式
- 相同状态使用相同的视觉样式
- 保持页面布局结构的一致性

### 6.2 易用性原则

- 减少用户操作步骤
- 提供明确的操作反馈
- 重要操作提供确认机制

### 6.3 清晰性原则

- 信息层级清晰
- 操作入口明确
- 状态标识直观

### 6.4 效率性原则

- 支持快速搜索和筛选
- 支持批量操作
- 减少页面跳转
