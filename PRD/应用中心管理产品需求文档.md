## 2. 功能目标与核心价值

### 2.1 功能目标

本模块用于统一管理门户已接入应用及快捷导航配置，解决应用入口分散、配置口径不一致、运营维护效率低的问题。通过标准化应用新增、配置、启停与快捷入口管理流程，保障门户首页应用展示准确、可控、可维护。

**主要目标：**

- 目标1：建立统一的应用台账，实现已接入应用可查询、可维护
- 目标2：提供应用新增与配置能力，支持名称、访问地址等核心信息维护
- 目标3：支持快捷导航配置，保障首页快捷入口可运营、可排序
- 目标4：提升后台管理员配置效率，降低前台展示异常风险
- 目标5：为后续应用分组、统计分析等能力提供基础数据支撑

### 2.2 核心价值

**对普通用户：**

- 首页应用入口更稳定，访问路径更清晰
- 快捷入口更贴近高频使用场景，减少查找成本

**对业务运营团队：**

- 应用接入与变更操作统一在后台执行，降低沟通成本
- 快捷导航管理可视化，支持快速上架/下架与排序调整

**对平台管理方：**

- 形成统一配置口径，减少重复配置和脏数据
- 便于权限控制与责任追踪，提升治理能力

## 3. 业务背景与使用场景

### 3.1 背景说明

随着统一门户承载的业务系统数量增加，当前应用入口管理存在以下问题：

- 应用信息分散，缺少统一台账，难以快速确认接入状态
- 应用地址、名称等配置变更路径不统一，容易导致前台展示错误
- 快捷导航配置缺少集中管理，首页高频入口维护效率低
- 缺少标准化的新增与维护流程，管理依赖人工沟通

因此需要建设“应用中心管理”模块，作为门户后台应用配置的统一入口。

### 3.2 使用场景

| 场景编号 | 场景名称 | 场景说明 | 典型用户 |
| --- | --- | --- | --- |
| S01 | 查询已接入应用 | 管理员通过应用列表查看当前已接入应用及其状态 | 应用中心管理员 |
| S02 | 新增应用 | 管理员新增一个业务系统入口，配置名称、URL等信息 | 应用中心管理员 |
| S03 | 修改应用配置 | 管理员对既有应用进行名称、地址、描述等信息更新 | 应用中心管理员 |
| S04 | 配置快捷导航 | 管理员将应用加入/移出快捷入口并维护展示顺序 | 应用中心管理员 |
| S05 | 快捷导航清理 | 管理员对已失效或低频应用进行快捷入口删除 | 应用中心管理员 |

## 4. 用户角色与职责

| 角色 | 职责 | 权限范围 |
| --- | --- | --- |
| 超级管理员 | 维护全局应用配置策略与权限分配 | 全量查看、新增、编辑、删除、快捷配置 |
| 应用中心管理员 | 日常维护应用及快捷入口配置 | 查看、新增、编辑、快捷配置、快捷删除 |
| 普通用户 | 使用门户前台应用入口 | 仅前台使用，无后台管理权限 |

## 6. 功能需求说明

### 6.1 页面1：应用列表页

#### 一、页面功能说明

展示已接入应用列表，支持查询、查看状态、查看快捷导航数量，并进入新增/编辑与快捷配置操作。

#### 二、UI 示意（留图区域）

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│  应用中心管理                                                [+ 新增应用]    │
├─────────────────────────────────────────────────────────────────────────────┤
│ 搜索条件：关键字（应用名称） 状态（启用/停用）                            │
│ [搜索] [重置]                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 应用名称 | 图标 | 访问地址 | 状态 | 快捷导航数量 | 排序 | 更新时间 | 操作   │
│ OA系统   | [图] | https://xx | 启用 | 3          | 1    | 2026-04-01 | 编辑 配置快捷导航 │
│ ERP系统  | [图] | https://yy | 启用 | 0          | 2    | 2026-04-02 | 编辑 配置快捷导航 │
├─────────────────────────────────────────────────────────────────────────────┤
│ 共 N 条记录                                                  分页组件        │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 三、功能点说明

- 支持按应用名称关键字模糊搜索
- 支持按应用状态筛选（启用、停用）
- 列表展示应用名称、应用图标、访问地址、状态、快捷导航数量、排序、更新时间
- 支持分页展示，默认按更新时间倒序
- 支持进入“新增应用”和“编辑应用”
- 支持在列表行触发“快捷导航配置”
- 支持点击“快捷导航数量”进入该应用的快捷导航查看/配置页

#### 四、关键操作流程

**查询流程：**

1. 用户输入关键字或选择状态
2. 点击“搜索”，系统返回筛选后的应用列表
3. 点击“重置”，恢复默认查询条件

**进入新增流程：**

1. 用户点击“新增应用”按钮
2. 系统打开应用新增页（或弹框）

**进入编辑流程：**

1. 用户在目标行点击“编辑”
2. 系统打开应用编辑页并回填当前数据

**快捷导航查看/配置流程：**

1. 用户在目标行点击“快捷导航数量”
2. 系统跳转到该应用对应的快捷导航查看/配置页
3. 用户可查看已关联快捷导航并执行新增、编辑、删除等配置

#### 五、业务规则

- 应用名称支持模糊匹配
- 状态筛选仅支持“启用/停用”
- 列表默认按更新时间降序排序
- 无匹配数据时展示空状态提示
- 应用图标为空时展示系统默认图标
- 快捷导航数量为0时仍显示可点击入口，用于快速新增快捷导航

#### 六、字段定义

| 字段名称 | 类型 | 是否必填 | 长度/精度 | 说明 |
| --- | --- | --- | --- | --- |
| 应用ID | 整数 | 是 | - | 系统唯一标识 |
| 应用名称 | 字符串 | 是 | 长度100 | 前台展示名称 |
| 应用图标 | 字符串 | 否 | 长度500 | 图标资源地址（URL或文件路径） |
| 访问地址 | 字符串 | 是 | 长度500 | 应用跳转URL |
| 状态 | 枚举 | 是 | - | 启用/停用 |
| 快捷导航数量 | 整数 | 是 | 0-9999 | 当前应用关联的快捷导航条目数量 |
| 排序 | 整数 | 否 | 1-9999 | 值越小越靠前 |
| 更新时间 | 日期时间 | 是 | - | 最近一次配置更新时间 |

### 6.2 页面2：应用新增/编辑页

#### 一、页面功能说明

用于创建新应用或维护已有应用配置，保障应用入口信息完整、可用。

#### 二、UI 示意（留图区域）

```text
┌──────────────────────────────────────────────────────────────┐
│  应用配置                                      [返回列表]     │
├──────────────────────────────────────────────────────────────┤
│ 应用名称*： [________________________]                       │
│ 应用图标 ： [上传图标] [预览] [清除]                         │
│ 访问地址*： [https://________________]                      │
│ 应用描述 ： [________________________]                       │
│ 状态*    ： (●启用) (○停用)                                 │
│ 排序     ： [____]                                           │
├──────────────────────────────────────────────────────────────┤
│                              [取消] [保存]                  │
└──────────────────────────────────────────────────────────────┘
```

#### 三、功能点说明

- 支持新增与编辑两种模式
- 新增模式下字段为空；编辑模式下自动回填
- 支持上传或选择应用图标，并提供图标预览
- 支持保存前表单校验与错误提示
- 保存成功后返回列表并刷新数据

#### 四、关键操作流程

**新增流程：**

1. 用户打开新增页
2. 填写应用名称、访问地址等信息
3. 点击“保存”，系统进行校验
4. 校验通过后保存并返回列表

**编辑流程：**

1. 用户从列表进入编辑页
2. 修改配置后点击“保存”
3. 系统校验通过后更新并返回列表

#### 五、业务规则

- 应用名称必填，且在系统内唯一
- 应用图标支持 png、jpg、svg 格式，建议尺寸 64x64
- 访问地址必填，需为合法 URL 格式
- 状态必选，默认“启用”
- 排序非必填，未填写时按系统默认值处理
- 保存失败时保留用户输入并提示失败原因

#### 六、字段定义

| 字段名称 | 类型 | 是否必填 | 长度/精度 | 说明 |
| --- | --- | --- | --- | --- |
| 应用名称 | 字符串 | 是 | 长度100 | 不可与已有名称重复 |
| 应用图标 | 字符串 | 否 | 长度500 | 图标资源地址，未配置时使用默认图标 |
| 访问地址 | 字符串 | 是 | 长度500 | 以 http:// 或 https:// 开头 |
| 应用描述 | 字符串 | 否 | 长度200 | 应用用途说明 |
| 状态 | 枚举 | 是 | - | 启用/停用 |
| 排序 | 整数 | 否 | 1-9999 | 用于前台展示排序 |

### 6.3 页面3：快捷导航配置页

#### 一、页面功能说明

用于配置应用是否进入门户首页快捷入口，并维护快捷展示顺序。

#### 二、UI 示意（留图区域）

```text
┌──────────────────────────────────────────────────────────────┐
│  快捷导航配置（应用：OA系统）                                │
├──────────────────────────────────────────────────────────────┤
│ 是否加入快捷入口*： (●是) (○否)                              │
│ 快捷图标         ： [上传图标] [预览] [继承应用图标]           │
│ 快捷排序         ： [____]                                   │
│ 生效状态*        ： (●启用) (○停用)                          │
├──────────────────────────────────────────────────────────────┤
│                              [取消] [保存]                  │
└──────────────────────────────────────────────────────────────┘
```

#### 三、功能点说明

- 支持配置应用是否展示在快捷入口
- 支持配置快捷入口独立图标，或继承应用图标
- 支持维护快捷排序
- 支持快捷入口单独启停控制
- 保存后同步影响门户首页快捷区展示

#### 四、关键操作流程

1. 用户在应用列表点击“配置快捷”
2. 系统打开快捷配置界面并回填当前配置
3. 用户调整“是否加入快捷入口”和排序
4. 点击“保存”后系统更新配置
5. 返回列表并展示最新快捷状态

#### 五、业务规则

- 仅“启用”状态应用可配置为快捷入口
- 当“是否加入快捷入口=否”时，快捷排序可为空
- 快捷排序值越小展示越靠前
- 同一应用在快捷列表仅允许存在一条配置
- 未配置快捷图标时默认继承应用图标

#### 六、字段定义

| 字段名称 | 类型 | 是否必填 | 长度/精度 | 说明 |
| --- | --- | --- | --- | --- |
| 是否加入快捷入口 | 布尔 | 是 | - | 快捷展示开关 |
| 快捷图标 | 字符串 | 否 | 长度500 | 快捷入口展示图标，未配置时继承应用图标 |
| 快捷排序 | 整数 | 否 | 1-9999 | 仅快捷入口启用时生效 |
| 生效状态 | 枚举 | 是 | - | 启用/停用 |

### 6.4 页面4：快捷导航管理页

#### 一、页面功能说明

以快捷导航视角集中管理已进入快捷入口的应用，支持新增与删除快捷项。
支持从应用列表“快捷导航数量”入口直达，并默认带入应用过滤条件。

#### 二、UI 示意（留图区域）

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│  快捷导航管理（OA系统）                                  [+ 新增快捷导航]    │
├─────────────────────────────────────────────────────────────────────────────┤
│ 快捷名称 | 图标 | 关联应用 | 访问地址 | 排序 | 状态 | 操作                  │
│ OA快捷   | [图] | OA系统   | https://x | 1    | 启用 | 删除                   │
│ ERP快捷  | [图] | ERP系统  | https://y | 2    | 启用 | 删除                   │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 三、功能点说明

- 展示当前所有快捷导航条目
- 支持新增快捷导航（从已接入应用中选择）
- 支持删除快捷导航
- 支持展示快捷导航关联的应用信息
- 支持展示并维护快捷图标
- 支持按“应用ID/应用名称”过滤查看，支持从应用列表携带过滤条件进入

#### 四、关键操作流程

**新增快捷导航流程：**

1. 点击“新增快捷导航”
2. 选择已接入且可用的应用
3. 设置快捷名称、图标、排序并保存
4. 列表刷新并显示新增条目

**删除快捷导航流程：**

1. 点击目标行“删除”
2. 弹出确认提示
3. 确认后删除并刷新列表

#### 五、业务规则

- 快捷导航必须关联已接入且启用的应用
- 同一应用不能重复新增为多个快捷条目
- 删除快捷导航不影响原应用主配置
- 快捷导航删除后前台快捷入口即时生效
- 快捷图标未配置时显示继承标识并使用应用图标

#### 六、字段定义

| 字段名称 | 类型 | 是否必填 | 长度/精度 | 说明 |
| --- | --- | --- | --- | --- |
| 快捷ID | 整数 | 是 | - | 快捷条目唯一标识 |
| 快捷名称 | 字符串 | 是 | 长度100 | 前台快捷展示名称 |
| 快捷图标 | 字符串 | 否 | 长度500 | 快捷展示图标地址，默认继承应用图标 |
| 关联应用ID | 整数 | 是 | - | 关联应用中心主应用 |
| 快捷访问地址 | 字符串 | 是 | 长度500 | 默认继承应用访问地址，可按策略覆盖 |
| 排序 | 整数 | 否 | 1-9999 | 快捷区展示顺序 |
| 状态 | 枚举 | 是 | - | 启用/停用 |

## 7. 页面交互逻辑说明

### 7.1 页面跳转关系

| 来源页面 | 交互操作 | 跳转目标 | 说明 |
| --- | --- | --- | --- |
| 应用列表页 | 点击“新增应用” | 应用新增/编辑页（新增模式） | 创建新应用配置 |
| 应用列表页 | 点击“编辑” | 应用新增/编辑页（编辑模式） | 修改现有应用配置 |
| 应用列表页 | 点击“配置快捷” | 快捷导航配置页 | 维护快捷入口配置 |
| 应用列表页 | 点击“快捷导航数量” | 快捷导航管理页（按应用过滤） | 默认携带应用ID过滤，仅展示当前应用快捷导航，并可直接配置 |

| 快捷导航管理页 | 点击“删除” | 当前页 | 删除后刷新列表 |
| 应用新增/编辑页 | 点击“保存” | 应用列表页 | 保存成功后返回并刷新 |

### 7.2 状态刷新机制

| 操作 | 刷新范围 | 刷新方式 |
| --- | --- | --- |
| 新增应用 | 应用列表 | 保存成功后返回列表自动刷新 |
| 编辑应用 | 应用列表、快捷状态 | 保存成功后刷新当前页与关联标识 |
| 配置快捷导航 | 应用列表、快捷导航管理页 | 保存成功后即时刷新 |
| 删除快捷导航 | 快捷导航管理页、前台快捷区 | 删除成功后后台列表刷新，前台按配置重新拉取 |
| 新增/删除快捷导航 | 应用列表中的快捷导航数量 | 保存成功后回到列表时数量实时刷新 |

### 7.3 关键交互细节

| 交互点 | 规则说明 |
| --- | --- |
| 点击快捷导航数量跳转 | 跳转时必须携带应用ID（必传）与应用名称（选传）作为过滤参数 |
| 目标页默认视图 | 快捷导航管理页默认仅展示该应用关联的快捷导航数据 |
| 页面标题展示 | 页面标题格式为“快捷导航管理（{应用名称}）”，应用名称缺失时显示应用ID |
| 新增快捷导航默认值 | 从该入口进入时，新增弹框默认预选当前应用，减少重复选择 |
| 返回列表行为 | 从快捷导航管理页返回应用列表后，自动定位到原应用行并刷新快捷导航数量 |

## 10. 验收标准

| 验收项 | 验收标准 |
| --- | --- |
| 功能完整性 | 功能清单中的5项能力均可正常操作 |
| 数据准确性 | 列表与配置详情一致，保存后数据正确回显 |
| 权限控制 | 未授权角色无法访问或调用后台管理能力 |
| 性能要求 | 列表查询响应时间 < 2s，保存配置响应时间 < 1s |
| 异常处理 | 参数校验、重复名称、非法URL均有明确提示 |
| 前后台一致性 | 快捷配置变更后，前台快捷入口展示结果正确 |
| 兼容性 | 支持 Chrome、Edge 主流浏览器 |

**具体验收用例：**

1. **应用列表查询**
   - [ ] 输入关键字可返回匹配应用
   - [ ] 状态筛选生效且结果正确
   - [ ] 无数据时显示空状态
   - [ ] 列表正确展示快捷导航数量，点击数量可进入对应配置页

2. **应用新增与配置**
   - [ ] 必填项为空时不能保存并有提示
   - [ ] URL 格式非法时拦截保存
   - [ ] 应用名称重复时禁止保存
   - [ ] 应用图标可上传、预览，未配置时显示默认图标
   - [ ] 保存成功后列表可见新增/修改结果

3. **快捷导航配置**
   - [ ] 可将应用加入快捷入口
   - [ ] 可移出快捷入口且不影响主应用
   - [ ] 快捷排序生效，前台展示顺序正确
   - [ ] 可配置快捷图标，未配置时继承应用图标

4. **快捷导航管理**
   - [ ] 可新增快捷导航条目
   - [ ] 同一应用不可重复新增快捷条目
   - [ ] 删除快捷导航后列表与前台展示同步更新

5. **权限与安全**
   - [ ] 超级管理员具备全量操作权限
   - [ ] 应用中心管理员权限符合矩阵定义
   - [ ] 普通用户无法访问后台管理页
