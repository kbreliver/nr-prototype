## 2. 功能目标与核心价值

### 2.1 功能目标

客户方案模块旨在规范化管理企业对客户的解决方案制定过程。通过实现从方案配置、报价计算到内部审批的全流程数字化，解决手工报价效率低、计算易出错、审批流程不透明等问题。

**主要目标：**
- 目标1：**标准化方案配置**，统一软件、硬件、服务的配置标准
- 目标2：**自动化报价计算**，系统自动计算各项小计、折扣及总价，减少人工错误
- 目标3：**流程化审批管理**，固化三级审批流程，确保方案合规
- 目标4：**提升协作效率**，为销售、商务和管理层提供统一的协作平台

### 2.2 核心价值

**对销售人员：**
- 快速生成标准化的报价单，提升响应速度
- 自动计算金额和折扣，避免低级错误
- 实时追踪审批进度，从容把控销售节奏

**对商务/管理层：**
- 统一管控价格体系和折扣权限
- 沉淀历史方案数据，便于成本分析和利润管控
- 移动化审批（规划中），提升决策效率

**对公司：**
- 建立规范的售前方案管理体系
- 积累方案知识库，支持复用
- 降低因报价错误导致的合规风险

## 3. 业务背景与使用场景

### 3.1 背景说明

随着业务扩展，售前阶段的方案制定面临挑战：
- 方案内容复杂，包含软件、硬件、服务多类目，Excel管理难以维护
- 报价计算逻辑复杂（折扣、税率、大写转换），人工计算耗时且易错
- 审批依赖线下或邮件，流转慢且难以追溯
- 缺乏历史报价参考，新员工上手慢

需建设统一的客户方案管理模块，实现方案的在线化、数字化管理。

### 3.2 使用场景

| 场景编号 | 场景名称 | 场景说明 | 典型用户 |
|---------|---------|----------|---------|
| S01 | 新建方案 | 销售针对特定客户需求，创建并配置新的解决方案 | 销售人员 |
| S02 | 方案报价 | 调整各配置项数量、设置折扣率、计算总价并生成报价 | 销售人员 |
| S03 | 方案审批 | 对提交的方案进行市场、商务、管理层三级审批 | 部门经理/商务/市场负责人 |
| S04 | 审批工作台 | 审批人查看待办事项，进行快速审批或查看详情 | 审批人员 |
| S05 | 方案导出 | 导出Excel或PDF格式的正式报价单发送给客户 | 销售人员 |
| S06 | 方案复用 | 复制已有方案作为新方案的基础，快速修改 | 销售人员 |

## 4. 用户角色与职责

| 角色 | 职责 | 权限范围 |
|------|------|----------|
| **销售人员** | 方案发起者 | 创建/编辑/删除(草稿)方案，配置产品，发起审批，导出报价单 |
| **方案经理** | 方案管理者 | 拥有所有方案的查看与编辑权限，管理方案库 |
| **部门市场负责人** | 一级审批人 | 审核方案的市场可行性及基本配置 (审批节点1) |
| **部门商务负责人** | 二级审批人 | 审核方案报价、利润率及商务条款 (审批节点2) |
| **部门经理** | 三级审批人 | 最终决策方案是否通过 (审批节点3) |

#### 三、功能点说明

- **搜索**：支持按方案名称、客户名称、状态（草稿/审批中/已发布/已驳回）、创建时间范围筛选。
- **列表展示**：核心字段包括方案编号、名称、客户、总金额（千分位格式）、状态（Tag区分颜色）、创建人、创建时间。
- **操作按钮**：
    - **查看**：所有状态可用，跳转详情页查看模式。
    - **编辑/删除**：仅“草稿”和“已驳回”状态可用。
    - **审批流程**：仅“审批中”状态显示，点击查看当前审批进度。
    - **复制**：所有状态可用，复制当前方案内容为新草稿。
- **新建方案**：点击弹出模态框，填写名称和客户后跳转详情页编辑。

#### 四、业务规则

- 方案编号自动生成，格式 `CS-YYYYMMDD-XXX`。
- 删除操作需二次确认，且只能删除草稿或已驳回的方案。
- 审批中的方案锁定，不可编辑。

#### 三、功能点说明

**1. 基本信息 (Basic Info)**
- 字段：方案编号（只读）、方案名称、客户名称（关联客户库）、联系人/电话（自动回填）、方案类型、行业领域、说明。
- 编辑模式下支持修改，查看模式下只读。

**2. 方案配置 (Configuration)**
- 分为“软件产品”、“硬件设备”、“服务项目”三个子Tab。
- **添加配置项交互**（重点优化）：
    - **硬件设备**：点击“添加硬件”按钮，弹出**硬件设备库选择弹窗**。
        - **搜索筛选**：弹窗顶部提供组合搜索，支持**按设备类型筛选**（如传感器、控制器等）和**关键词模糊检索**（匹配名称、型号、编码）。
        - **列表展示**：列表包含设备编码、名称、型号、品牌、类型、单价、库存等关键信息。
        - **数据过滤**：
            - 仅展示状态为“**已启用**”的设备。
            - **自动过滤掉已加入当前方案的设备**，避免重复添加。
        - **选择操作**：
            - 支持勾选多条设备记录，支持**跨页选择**（切换搜索条件或翻页后，已选记录保留）。
            - 底部“确定”按钮**实时显示已选数量**（如“确定 (3)”）。
            - 点击“确定”后批量加入方案配置列表。
    - **软件/服务**：采用类似的弹窗选择模式，确保只能选择有效的产品/服务。
- **列表编辑**：
    - 列表字段：产品名称、型号/版本、单价、数量、小计。
    - 支持行内编辑“数量”，系统自动根据 `单价 * 数量` 更新小计。
    - 支持**单条删除**和**批量删除**操作（勾选多项后点击列表头部的“批量删除”按钮）。
- **报价计算**：
    - 自动计算各项小计：`小计 = 单价 * 数量`。

**3. 方案报价 (Quotation)**
- **报价明细**：汇总所有配置项，支持针对单项设置折扣率。
- **费用汇总**：自动计算软件/硬件/服务分项总计。
- **整单计算**：支持设置整单折扣率、附加费用。
- **总价**：`Total = (Subtotal * (1-Discount)) + Additional`。
- **大写金额**：系统自动将总价转换为中文大写。
- **报价有效期**：必填项，通过日期选择器选择报价的有效截止日期，只能选择当天及以后的日期。
- **报价说明**：填写报价相关说明，如包含内容、不包含内容等。
- **导出**：支持导出Excel/PDF报价单，报价单中包含报价有效期信息。

**4. 审批记录 (Approval)**
- 展示审批流程图（Timeline），显示各节点状态（已通过/待审批/已驳回）。
- 显示审批日志：审批人、时间、意见。

#### 四、业务规则

- 提交审批前必须完成配置且总金额大于0。
- 提交审批前必须选择报价有效期。
- 保存报价时必须选择报价有效期。
- 报价有效期必须选择当天或未来日期，不能选择过去的日期。
- 金额保留2位小数，计算需精准。
- 审批中状态下，详情页全字段只读。

### 7.2 状态刷新机制

- **自动计算**：在方案配置或报价Tab修改数量、单价、折扣时，右侧或底部的总价需实时重新计算，无需手动刷新。
- **审批流转**：提交审批或审批通过后，列表页状态需自动更新。

## 10. 验收标准

| 验收项 | 验收标准 |
|--------|----------|
| **配置管理** | 能正确添加软/硬件/服务，小计计算无误 |
| **报价计算** | 总价 = (小计 - 折扣) + 附加费，大写转换正确 |
| **报价有效期** | 必填验证生效，保存和提交审批时未选择会提示错误；日期选择器只能选择今天及以后的日期 |
| **审批流程** | 提交后状态变更为"审批中"，审批人能看到待办，驳回后状态变更为"已驳回"且可编辑 |
| **数据权限** | 销售只能看自己的，审批人能看待办的 |
| **导出功能** | 导出的PDF/Excel内容与页面显示一致，格式整齐，包含报价有效期信息 |

| **标准方案** | 基于公司现有产品组合的常规方案 |
| **定制方案** | 包含大量定制开发或非标产品的方案 |
| **折扣率** | 百分比格式，表示折后价格占原价的比例。100%代表原价无折扣，90%代表打9折，80%代表打8折 |
| **折扣金额** | 实际减少的金额，计算公式：折扣金额 = 原价 × (100% - 折扣率) |
| **附加费用** | 除产品外的实施差旅、特殊包装等费用 |
