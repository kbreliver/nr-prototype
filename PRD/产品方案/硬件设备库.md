## 2. 功能概述

### 2.1 模块定位

硬件设备库模块用于统一维护公司自研及代理的硬件设备的基础信息，包括设备型号、参数、库存、单价、状态、编号等内容；并可追溯设备的使用记录，为销售报价、项目实施及库存管理提供支撑。

### 2.2 核心价值

- 建立标准化硬件设备信息库，减少信息重复维护
- 支撑解决方案配置、成本测算及报价自动化
- 提升项目中设备选型、采购及追踪效率
- 为公司资产管理和运维提供数据基础

## 3. 业务场景

| 场景 | 描述 |
|------|------|
| 场景1：产品配置 | 解决方案经理在配置方案时，从硬件设备库中选择标准设备型号和单价 |
| 场景2：库存核查 | 运维或采购人员可快速查看库存数量与设备状态 |
| 场景3：追踪使用 | 可追溯设备被引用于哪些项目或订单中，查看使用记录 |

## 4. 用户角色

| 角色 | 职责 | 权限级别 |
|------|------|----------|
| 产品经理 | 定义设备型号、属性 | 维护 |
| 采购人员 | 管理库存与单价 | 编辑 |
| 运维人员 | 查看库存状态与使用记录 | 查看 |
| 项目经理 | 查看设备信息用于项目配置 | 查看 |
| 管理员 | 审批、删除、权限分配 | 超级管理 |

#### 三、功能点说明

- 支持按设备编号、名称、型号、状态、类别等多条件搜索
- 列表每行前含复选框，用于批量删除、导出、停用等操作

- 每页显示 20 条数据，可分页查看
- 支持导出为 Excel
- 点击设备编号可进入详情页

#### 四、关键操作流程

**新增设备流程**：
1. 用户点击"新增设备"按钮
2. 跳转到设备详情页（空白表单，编辑模式）
3. 填写设备基本信息（编号、名称、型号、类别等）
4. 切换到"参数信息"标签页，添加技术参数
5. 点击"保存"按钮，系统验证表单并保存数据
6. 页面切换到查看模式，显示成功提示

**删除设备流程**：
1. 用户点击某设备的"删除"按钮
2. 弹出确认对话框："确定要删除设备"XXX"吗？"
3. 用户点击"确定"
4. 系统校验设备是否被项目引用
5. 如已被引用，提示"该设备已被项目使用，无法删除"，禁止删除
6. 如未被引用，执行删除操作
7. 刷新列表页，显示成功提示

**批量删除流程**：
1. 用户勾选多个设备
2. 点击"批量删除"按钮
3. 弹出确认对话框："确定要删除选中的 X 个设备吗？"
4. 用户点击"确定"
5. 系统批量校验是否被引用
6. 删除未被引用的设备，被引用的设备跳过并提示
7. 刷新列表页，显示操作结果

#### 五、业务规则

- 删除设备需校验是否被项目或方案引用
- 同一设备编号唯一且不可重复
- 禁止直接修改库存字段，库存通过入库操作自动计算

#### 六、字段定义

| 字段名称 | 类型 | 是否必填 | 长度/精度 | 说明 |
|----------|------|----------|-----------|------|
| 设备编号 | 字符串 | 是 | 长度20 | 系统自动生成或手动录入 |

| 设备型号 | 字符串 | 是 | 长度30 | 型号标识 |
| 设备类别 | 枚举 | 是 | - | 如传感器、网关、服务器等 |
| 品牌 | 字符串 | 否 | 长度30 | 品牌名称 |
| 单价 | 数值 | 是 | 精度2 | 设备单价 |
| 库存数量 | 数值 | 否 | 整数 | 当前库存 |
| 状态 | 枚举 | 是 | - | 启用 / 停用 |
| 更新时间 | 日期时间 | 否 | - | 最近修改时间 |

  - 平滑曲线，带渐变填充效果

#### 四、关键操作流程

**库存入库流程**：
1. 用户在列表页或详情页点击"库存管理"按钮
2. 跳转到库存管理页，显示设备信息、库存记录和趋势图
3. 用户点击"入库"按钮
4. 右侧滑出入库抽屉，操作类型自动设置为"入库"且禁用修改
5. 用户填写入库信息：
   - 操作数量（必填，必须大于0）
   - 操作日期（必填，默认当前日期）
   - 来源/去向（必填）
   - 关联项目（选填）
   - 备注（选填）
6. 用户点击"提交"按钮，系统验证数据
7. 验证通过后，更新库存数量，记录操作日志
8. 抽屉关闭，刷新库存记录表格和趋势图，显示成功提示

**库存出库流程**：
1. 用户在库存管理页点击"出库"按钮
2. 右侧滑出出库抽屉，操作类型自动设置为"出库"且禁用修改
3. 用户填写出库信息：
   - 操作数量（必填，必须大于0）
   - 操作日期（必填，默认当前日期）
   - 来源/去向（必填）
   - 关联项目（必填，出库时强制要求）
   - 备注（选填）
4. 系统实时校验库存是否充足
5. 用户点击"提交"按钮，系统验证数据
6. 验证通过后，扣减库存数量，记录操作日志
7. 抽屉关闭，刷新库存记录表格和趋势图，显示成功提示
8. 如果库存不足，显示错误提示："库存不足，当前库存：XX"

**取消操作流程**：
1. 用户在抽屉中点击"取消"按钮或点击关闭图标
2. 抽屉关闭，不保存任何数据
3. 表单数据被重置

#### 五、业务规则

- 每次入库/出库操作自动更新库存数量
- 出库操作需校验库存充足，不足时提示错误
- 出库操作必须填写关联项目，入库则为可选
- 操作数量不能为0，必须为正整数
- 抽屉中的操作类型根据点击的按钮自动设置，不可修改
- 提交成功后自动关闭抽屉，刷新数据并重新渲染图表
- 库存变动趋势图按时间顺序展示，最新记录在右侧

| 备注 | 文本 | 否 | 长度200 | 操作备注说明 |

   - 调拨数量显示为蓝色

   - 主色调：跟随系统主题色
   - 曲线平滑处理，数据点用圆形标记
   - 图表高度：400px

## 7. 页面交互逻辑说明

### 7.1 页面跳转关系

| 来源页面 | 交互操作 | 跳转目标 | 说明 |
|----------|----------|----------|------|
| 硬件设备列表页 | 点击"新增设备"按钮 | 设备详情页（新建模式） | 打开空白表单，mode=edit |
| 硬件设备列表页 | 点击设备编号链接 | 设备详情页（查看模式） | 展示设备完整信息，只读模式 |
| 硬件设备列表页 | 点击"查看"按钮 | 设备详情页（查看模式） | 展示设备完整信息，只读模式 |
| 硬件设备列表页 | 点击"编辑"按钮 | 设备详情页（编辑模式） | 打开编辑表单，mode=edit |
| 硬件设备列表页 | 点击"库存管理"按钮 | 库存管理页 | 跳转到该设备的库存管理页面 |
| 硬件设备列表页 | 点击"删除"按钮 | 当前页面 | 弹出确认对话框，确认后刷新列表 |
| 硬件设备列表页 | 点击"导出"按钮 | 当前页面 | 导出Excel文件，不跳转 |
| 设备详情页 | 点击"返回"按钮 | 硬件设备列表页 | 返回上一页（浏览器返回） |
| 设备详情页 | 点击"编辑"按钮 | 当前页面 | 切换到编辑模式，不跳转 |
| 设备详情页 | 点击"保存"按钮 | 当前页面 | 保存后切换到查看模式 |
| 设备详情页 | 点击"库存管理"按钮 | 库存管理页 | 跳转到该设备的库存管理页面 |
| 设备详情页 | 点击"删除"按钮 | 硬件设备列表页 | 确认删除后返回列表页 |
| 库存管理页 | 点击"返回"按钮 | 上一页面 | 返回上一页（可能是列表页或详情页） |
| 库存管理页 | 点击"入库"按钮 | 当前页面 | 打开入库抽屉，不跳转 |
| 库存管理页 | 点击"出库"按钮 | 当前页面 | 打开出库抽屉，不跳转 |
| 库存管理页 | 抽屉中点击"提交"按钮 | 当前页面 | 提交后关闭抽屉，刷新数据和图表 |
| 库存管理页 | 抽屉中点击"取消"按钮 | 当前页面 | 关闭抽屉，不保存数据 |

### 7.2 状态刷新机制

| 操作 | 刷新范围 | 刷新方式 |
|------|----------|----------|
| 新增设备 | 列表数据 | 保存后返回列表页自动刷新 |
| 编辑设备 | 当前设备详情 | 保存后重新加载设备数据 |
| 删除设备 | 列表数据 | 删除后自动刷新列表 |
| 入库/出库操作 | 库存记录、趋势图、设备信息 | 提交后刷新所有相关数据 |
| 批量删除 | 列表数据 | 删除后自动刷新列表 |

## 10. 验收标准

| 验收项 | 验收标准 |
|--------|----------|
| 界面一致性 | 所有页面UI风格一致、字段对齐 |
| 数据准确性 | 入库出库操作库存变化正确 |
| 权限控制 | 不同角色访问权限符合预期 |
| 性能要求 | 查询响应时间 < 2s |
