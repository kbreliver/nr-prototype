# 硬件设备库模块

## 功能概述

硬件设备库模块用于统一维护公司自研及代理的硬件设备的基础信息，包括设备型号、参数、库存、单价、状态、编号等内容；并可追溯设备的使用记录，为销售报价、项目实施及库存管理提供支撑。

## 文件结构

```
hardware/
├── README.md           # 模块说明文档
├── types.ts           # TypeScript 类型定义
├── index.vue          # 硬件设备列表页
├── detail.vue         # 设备详情页
└── inventory.vue      # 库存管理页
```

## 页面说明

### 1. 硬件设备列表页 (`index.vue`)

**路由**: `/product-solutions/hardware`

**功能特性**:
- ✅ 多条件搜索（设备编号、设备名称、设备类别、状态）
- ✅ 表格展示（支持排序、分页）
- ✅ 批量操作（删除、导出）
- ✅ 行内操作（查看、编辑、库存管理、删除）

**表格字段**:
- 设备编号（可点击查看详情）
- 设备名称
- 型号
- 类别
- 品牌
- 单价
- 库存
- 状态（启用/停用）
- 更新时间
- 操作

### 2. 设备详情页 (`detail.vue`)

**路由**: 
- 查看模式: `/product-solutions/hardware/detail/:id`
- 编辑模式: `/product-solutions/hardware/detail/:id?mode=edit`
- 新建模式: `/product-solutions/hardware/detail?mode=edit`

**功能特性**:
- ✅ 支持查看/编辑模式切换
- ✅ 标签页形式展示（基本信息、参数信息、使用记录）
- ✅ 表单验证
- ✅ 动态参数管理（添加/删除技术参数）

**标签页内容**:

1. **基本信息**
   - 设备编号、名称、型号、类别
   - 品牌、单价、状态
   - 规格说明、备注
   - 只读信息：库存、使用次数、创建/更新信息

2. **参数信息**
   - 技术参数列表（键值对形式）
   - 支持动态添加/删除参数
   - 可编辑参数值

3. **使用记录**
   - 设备在哪些项目中使用
   - 客户名称、项目编号、使用数量
   - 部署日期、使用状态

### 3. 库存管理页 (`inventory.vue`)

**路由**: `/product-solutions/hardware/inventory/:id`

**功能特性**:
- ✅ 设备信息展示
- ✅ 库存操作（入库、出库）- 使用抽屉形式
- ✅ 库存记录查询
- ✅ 库存变动趋势图表（ECharts）
- ✅ 业务规则校验

**功能模块**:

1. **设备信息卡片**
   - 显示设备编号、名称、型号
   - 突出显示当前库存数量

2. **库存记录表格**
   - 标题栏右侧：入库、出库按钮
   - 操作日期、类型、数量
   - 来源/去向、关联项目
   - 操作人、库存结余
   - 数量以颜色区分（绿色=入库，红色=出库）

3. **库存操作抽屉**
   - 点击入库/出库按钮时从右侧滑出
   - 垂直布局的表单
   - 操作类型（根据点击按钮自动设置，不可修改）
   - 操作数量、日期
   - 来源/去向
   - 关联项目（出库必填）
   - 备注（多行输入）

4. **库存变动趋势图**
   - 使用 ECharts 面积图展示
   - X 轴：操作日期
   - Y 轴：库存数量
   - 平滑曲线，带渐变填充
   - 支持数据点悬停查看详情

## 业务规则

1. **设备编号规则**
   - 格式: `HD-XXXXXXX`
   - 唯一且不可重复

2. **库存操作规则**
   - 出库时必须校验库存充足
   - 出库时必须填写关联项目
   - 入库数量为正数，出库数量转为负数
   - 自动计算库存结余

3. **删除规则**
   - 删除设备前需校验是否被项目引用
   - 已使用的设备不可删除

4. **权限规则**（待实现）
   - 所有用户可查看和编辑
   - 后续可根据角色细化权限

## 后端 API

### Mock API 文件

```
apps/backend-mock/api/product-solutions/
├── hardware.ts           # 设备列表 API
└── hardware/
    ├── [id].ts          # 设备详情 API
    └── inventory.ts     # 库存管理 API
```

### API 端点

1. **GET `/api/product-solutions/hardware`**
   - 获取设备列表
   - 支持分页、搜索、筛选

2. **GET `/api/product-solutions/hardware/[id]`**
   - 获取设备详情
   - 包含基本信息、参数、使用记录

3. **GET/POST `/api/product-solutions/hardware/inventory`**
   - GET: 查询库存记录
   - POST: 新增库存操作

## 技术栈

- **前端框架**: Vue 3 (Composition API)
- **UI 组件库**: Ant Design Vue
- **样式**: Tailwind CSS
- **类型系统**: TypeScript
- **路由**: Vue Router
- **后端模拟**: Nitro (H3)

## 数据结构

详见 `types.ts` 文件，主要类型包括：

- `HardwareDevice` - 硬件设备信息
- `InventoryRecord` - 库存记录
- `UsageRecord` - 使用记录
- `DeviceForm` - 设备表单
- `InventoryForm` - 库存操作表单
- `SearchForm` - 搜索表单

## 使用说明

### 查看设备列表
1. 访问 `/product-solutions/hardware`
2. 使用搜索框筛选设备
3. 点击设备编号查看详情

### 添加新设备
1. 点击"新增设备"按钮
2. 填写设备基本信息
3. 添加技术参数
4. 保存

### 管理库存
1. 在列表页点击"库存管理"
2. 选择操作类型（入库/出库）
3. 填写数量和相关信息
4. 提交操作
