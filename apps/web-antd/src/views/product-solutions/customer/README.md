# 客户方案模块

## 概述

客户方案模块是OMS运营管理系统的核心功能之一，用于管理客户解决方案的配置、报价、审批全流程。

## 功能特性

### 1. 客户方案列表 (`index.vue`)

- **功能**：展示所有客户方案的列表
- **特性**：
  - 多条件搜索（方案名称、客户名称、状态、创建时间）
  - 分页查询
  - 批量操作（批量删除）
  - 导出Excel
  - 状态筛选
  - 方案复制

### 2. 方案详情 (`detail.vue`)

包含4个标签页：

#### 2.1 基本信息
- 方案基础信息录入
- 客户信息选择
- 方案类型和行业领域
- 方案统计卡片展示

#### 2.2 方案配置
- 软件产品配置（从软件产品库选择）
- 硬件设备配置（从硬件设备库选择）
- 服务项目配置（从服务库选择）
- 自动计算小计
- 配置项编辑和删除

#### 2.3 方案报价
- 自动汇总各类费用
- 折扣率设置和实时计算
- 附加费用录入
- 总价自动转换为中文大写
- 提交审批
- ~~导出Excel/PDF报价单~~ (v1.1)

#### 2.4 审批记录
- 可视化审批流程图
- 审批记录列表
- 审批操作（通过/驳回）
- 审批意见填写

### 3. 审批工作台 (`approval-workspace.vue`)

- **功能**：为审批人提供统一的审批管理界面
- **特性**：
  - 待审批/已审批/全部方案切换
  - 待审批数量徽章提醒
  - 快速审批对话框
  - 查看方案详情

## 技术实现

### 文件结构

```
customer/
├── index.vue              # 方案列表页
├── detail.vue             # 方案详情页
├── approval-workspace.vue # 审批工作台
├── types.ts               # 类型定义
├── utils.ts               # 工具函数
└── README.md              # 本文档
```

### 关键类型

- `CustomerSolution` - 客户方案基本信息
- `SoftwareConfigItem` - 软件产品配置项
- `HardwareConfigItem` - 硬件设备配置项
- `ServiceConfigItem` - 服务项目配置项
- `SolutionQuotation` - 方案报价信息
- `ApprovalRecord` - 审批记录

### 工具函数

#### 金额处理
- `formatAmount(amount)` - 格式化金额
- `formatCurrency(amount)` - 格式化金额（带货币符号）
- `convertAmountToChinese(amount)` - 转换为中文大写金额
- `calculateSubtotal(quantity, unitPrice)` - 计算小计
- `calculateDiscountAmount(subtotal, discountRate)` - 计算折扣金额
- `calculateTotalAmount(subtotal, discountAmount, additionalFee)` - 计算总价

#### 其他工具
- `generateSolutionCode()` - 生成方案编号
- `formatDate(date, format)` - 格式化日期
- `getApprovalNodeName(nodeId)` - 获取审批节点名称

## 业务流程

### 方案创建流程
1. 点击"新建方案"
2. 填写基本信息
3. 配置软件/硬件/服务
4. 生成报价
5. 提交审批

### 审批流程
1. 部门市场负责人审批（一级）
2. 部门商务负责人审批（二级）
3. 部门经理审批（三级）

审批流程固定为三级，不再基于金额动态调整。

### 状态流转
- **草稿** → 可编辑、可删除
- **审批中** → 只读、不可编辑
- **已发布** → 只读、可复制
- **已驳回** → 可编辑、可重新提交

```typescript
// 复制方案
/product-solutions/customer/detail?mode=edit&copy=:id

// 审批工作台
/product-solutions/customer/approval-workspace
```

## 权限控制

### 角色权限
- **销售人员**：创建、编辑自己的方案、提交审批
- **方案经理**：创建、编辑所有方案
- **部门市场负责人**：查看、审批本部门方案（一级审批）
- **部门商务负责人**：查看、审批方案报价、调整折扣（二级审批）
- **部门经理**：查看、最终审批本部门方案（三级审批）

### 操作权限
- 草稿状态可编辑、删除
- 审批中状态只读
- 已发布状态只读，可复制
- 已驳回状态可编辑、重新提交

## 使用说明

### 创建新方案
1. 在列表页点击"新建方案"
2. 填写方案基本信息并保存
3. 切换到"方案配置"标签页
4. 添加软件产品、硬件设备、服务项目
5. 点击"保存配置"
6. 切换到"方案报价"标签页
7. 调整折扣率和附加费用
8. 填写报价说明
9. 点击"提交审批"

### 审批方案
1. 进入审批工作台
2. 查看待审批方案列表
3. 点击"审批"按钮快速审批
4. 或点击"查看"进入详情页查看完整信息
5. 填写审批意见
6. 点击"通过"或"驳回"

### 导出报价单（v1.1计划）
导出功能将在v1.1版本中实现，届时支持：
- Excel格式报价单导出
- PDF格式报价单导出
- 方案列表批量导出

## 注意事项

1. **浏览器兼容性**：建议使用Chrome、Edge、Firefox等现代浏览器
2. **数据校验**：提交审批前系统会自动校验数据完整性
3. **金额精度**：所有金额计算保留2位小数
4. **方案编号**：系统自动生成，格式为 CS-YYYYMMDD-XXX
5. **导出功能**：导出功能将在v1.1版本中提供
