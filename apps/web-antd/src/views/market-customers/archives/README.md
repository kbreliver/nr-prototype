# 客户档案模块

## 功能概述

客户档案模块是OMS运营管理系统中市场客户管理的核心功能，提供完整的客户信息管理能力。

## 功能特性

### 1. 客户档案列表 (`index.vue`)

- **多条件搜索**
  - 客户名称、客户编号
  - 所属行业、客户地区
  - 客户级别、客户状态
  
- **列表展示**
  - 支持排序和分页（20条/页，可切换10/20/50/100）
  - 客户级别和状态使用不同颜色的Tag标签
  - 点击客户编号可快速跳转详情
  
- **操作功能**
  - 新建客户（快速创建后跳转详情页完善）
  - 查看、编辑、删除客户
  - 批量操作（预留）
  - 导出功能（下一期）

### 2. 客户详情页 (`detail.vue`)

包含4个主要标签页：

#### 基本信息标签页
- 客户基本资料（名称、简称、信用代码、注册资本等）
- 行业与地区信息
- 客户级别与状态管理
- 企业信息（成立日期、法人、网站、地址）
- 客户标签管理（支持多选和自定义）
- 客户简介
- 查看/编辑模式切换

#### 组织架构标签页
- **左右分栏布局**
  - 左侧：树形组织结构展示
  - 右侧：部门详情编辑
  
- **核心功能**
  - 添加/编辑/删除部门
  - 支持拖拽调整层级（最多10层）
  - 复用组织架构模板
    - 本公司组织架构
    - 其他客户组织架构
    - 标准行业模板
  - 部门信息管理（名称、负责人、电话、职能）

#### 联系人标签页
- **联系人列表**
  - 搜索：姓名、职位、所属部门
  - 手机号脱敏显示（138****0001）
  - 主要联系人星标标识
  
- **联系人管理**
  - 添加/编辑/删除联系人
  - 完整信息：姓名、性别、职位、部门、手机、邮箱、固话、微信、备注
  - 设置主要联系人（支持多个）
  - 所属部门从组织架构中选择

#### 业务历史标签页
- **业务统计卡片**
  - 商机数、方案数、合同数、项目数
  - 成交额、回款额、回款率
  
- **业务时间轴**
  - 按时间倒序展示
  - 支持业务类型筛选（商机、方案、合同、项目）
  - 支持时间范围筛选（最近一月/三月/半年/一年/全部）
  - 显示业务编号、名称、金额、状态
  - 一键跳转到对应业务详情

### 3. 统计数据展示

- 页面顶部统计卡片（仅详情页）
  - 商机、方案、合同、项目数量
  - 累计成交额

## 技术实现

### 文件结构

```
archives/
├── index.vue          # 客户档案列表页
├── detail.vue         # 客户详情页
├── types.ts           # TypeScript类型定义
├── utils.ts           # 工具函数
├── mock.ts            # Mock数据
└── README.md          # 说明文档
```

### 核心类型

- `CustomerProfile` - 客户基本信息
- `OrganizationNode` - 组织架构节点
- `ContactPerson` - 联系人信息
- `BusinessHistory` - 业务历史记录
- `CustomerStatistics` - 客户统计数据

### 工具函数

- `generateCustomerCode()` - 生成客户编号（CUS-YYYYMMDD-XXX）
- `maskPhone()` - 手机号脱敏
- `validatePhone()` - 手机号验证
- `validateEmail()` - 邮箱验证
- `validateCreditCode()` - 统一社会信用代码验证
- `formatCurrency()` - 金额格式化

### 数据关联

- 与客户方案模块集成
- 客户数据在两个模块间保持一致
- 业务历史关联到商机、方案、合同、项目模块

## 业务规则

### 客户档案
- 客户编号自动生成，格式：CUS-YYYYMMDD-XXX
- 客户名称必填且不能重复
- 统一社会信用代码如填写则必须唯一（18位）
- 客户级别：重点客户（红色）、普通客户（蓝色）、潜在客户（灰色）
- 客户状态：潜在客户、意向客户（蓝色）、合作中（绿色）、已流失（灰色）

### 组织架构
- 最多支持10层级嵌套
- 部门名称在同一层级下不能重复
- 删除部门前需确保该部门下无子部门和联系人
- 支持拖拽调整层级和顺序

### 联系人
- 联系人姓名必填
- 手机号、邮箱格式验证
- 列表中手机号中间4位打码
- 一个客户可以有多个主要联系人
- 所属部门删除后，联系人的部门信息自动清空

### 权限控制
- 销售人员：创建、编辑自己负责的客户
- 销售经理：查看、编辑本部门所有客户
- 客服人员：查看、编辑客户基本信息和联系人
- 项目经理：查看、编辑项目相关客户
- 管理层：查看所有客户
- 管理员：超级权限
